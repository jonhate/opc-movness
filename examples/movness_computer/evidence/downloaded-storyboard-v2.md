# 校园一小时

**60秒短片 · 分镜与拍摄清单**

把平常的一小时，拍成值得记住的一分钟。

## 分镜

| 时间 | 画面 | 声音与节奏 |
| --- | --- | --- |
| 00—06秒 | 教室门被轻轻推开，视线进入空教室 | 保留开门声，音乐由弱变强 |
| 06—14秒 | 走廊脚步、窗边树影，两个细节切换 | 脚步踩在节拍上 |
| 14—22秒 | 笔尖落下，纸页翻动，镜头从近景拉远 | 用翻页声衔接下一镜 |

| 34—45秒 | 图书馆窗边，一束光停在书页上 | 音乐短暂留白 |
| 45—55秒 | 长椅上的背影，抬头望向树梢 | 让环境声重新出现 |
| 55—60秒 | 回到教室的窗边，出现片名 | 字幕淡入，画面自然结束 |

## 手机拍摄清单

- 开拍前擦净镜头，统一使用横屏。
- 每个镜头多留2秒，方便电脑剪辑。
- 先拍空镜，再拍动作；每个动作留一条固定机位备用。
- 拍完按“教室、走廊、操场、图书馆”归类。
