# Movness · 跨设备个人智能体

**让智能体在手机与电脑上连续完成一个目标。**

Movness 将手机和电脑都作为智能体的感知环境与行动空间：它可以读取已授权的手机界面、执行手机操作，调用已配对电脑上的 DSH 完成工作，再将成果取回手机查看、分享和继续修改。手机侧提供示范操作的录制与回放，减少重复配置。

## 当前能力

| 能力 | r50 实现 |
| --- | --- |
| AI 对话与执行 | 复用 Operit 的模型、会话与工具执行链；简化为统一的 AI 对话入口 |
| 手机行动 | 在系统权限和工具授权范围内读取界面、启动应用、点击、输入与滚动 |
| 电脑协作 | 复用 DSH 远程插件进行二维码配对、选择会话、提交任务、查询结果与停止会话 |
| 成果返回 | 将电脑文件取回手机，保存与预览，续改时保留旧版 |
| 示范学习 | 用户主动录制操作事件，本机保存并回放；目标缺失或不唯一时停止 |
| 自动任务 | 使用底座已有的时间与条件触发任务体系 |

示范学习是操作复用，不是模型训练。电脑成果目前在「连接 DSH」的成果列表中查看。DSH 插件市场和主对话内成果卡尚未接入。

## 开始使用

1. 下载 Release 内的 `Movness-r50.apk`，在 Android 8.0 及以上的 arm64 设备安装。已有 r46/r48/r49 预览版可按系统流程覆盖安装；保留原应用数据请勿先卸载。
2. 按首次引导填写自己的模型接口地址、密钥和模型名称，并按需开启手机系统权限与连续执行授权。
3. 需要电脑协作时，使用顶部「连接 DSH」识别电脑远程插件提供的配对码，在电脑批准授权后选择会话。
4. 在 AI 对话中表达目标，查看工具执行状态与实际成果。需要复用操作时进入「示范学习」。

安装包包名：`io.movness.app.operit.preview`。r45 旧线使用另一包名，其数据不会自动迁移。

## 源码与继续开发

当前仓库含固定上游源代码、r46/r49/r50 修改覆盖层合成后的可编辑工程、r48 电脑工具源码和 r50 手机工具源码。Release 中额外提供完整源码交接包（已排除签名模板），含恢复基线、依赖归档和精确 APK 补丁。

- Android 界面与适配：`app/src/main/java/io/movness/ui/`
- 手机工具：`development/r50/phone-package/`
- 电脑工具：`examples/movness_computer/`
- 构建与恢复：[BUILD_CURRENT.md](docs/BUILD_CURRENT.md)
- 测试及发布记录：`development/r50/evidence/`、[校验清单](docs/RELEASE_MANIFEST.json)
- DSH 接力工作单：`relay/` 与当前交接文档

当前 APK 使用 Java 17、D8 与 Apktool 对既有 APK 重组并沿用原证书签名。合成后的完整 Gradle 工程尚未重新完整构建；不要将源码归档视为该路线已验证。应用签名私钥、用户模型密钥与电脑配对凭证不属于公开发布内容。

## 开源来源与许可

Movness 基于 [Operit](https://github.com/AAswordman/Operit) 固定版本二次开发，复用其模型接入、会话、工具、权限及自动任务体系；终端来自 [OperitTerminalCore](https://github.com/AAswordman/OperitTerminalCore)。电脑协作适配 DSH 及其现有远程插件。

本项目新增与调整集中在 Movness 的统一交互、跨设备配对与任务适配、成果回传与版本保留、示范操作复用、简化引导及品牌文案。上游能力和代码不作为 Movness 的独立原创成果。
